# 🎓 NotesPoint — Standardized Academic Repository

[![Live Website](https://img.shields.io/badge/Website-Live-brightgreen?style=for-the-badge&logo=vercel)](https://notespoint-sepia.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=for-the-badge)](LICENSE)

**NotesPoint** is a comprehensive, student-friendly academic portal designed for Grades 9–12 and competitive entrance examination aspirants (JEE, NEET, CUET). It provides 100% free NCERT notes, chapter-wise solutions, formula sheets, and past year question papers (PYQs).

---

## 🚀 Live Demo
🔗 **Visit Live Site:** [notespoint-sepia.vercel.app](https://notespoint-sepia.vercel.app/)

---

## ✨ Key Features

- 📚 **Curriculum Alignment:** Full subject coverage for Class 9, 10, 11, 12 & Competitive Exams.
- 🎨 **Adaptive Color Themes:** Dynamic grade-specific pastel UI for seamless navigation.
- ⭐ **Bookmarks & Saved Notes:** Save and manage important materials directly in local storage.
- ⏱️ **Daily Study Tracker:** Built-in dashboard timer and progress tracker for daily study goals.
- 📱 **Fully Responsive:** Smooth mobile-drawer navigation and zero-friction PDF access.
- 🤖 **Interactive AI Assistant:** Built-in academic guide for quick subject lookup.

---

## 🛠️ Built With

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Storage & Database:** IndexedDB & Firebase Firestore
- **Deployment:** Vercel / GitHub Pages
- **Icons & Typography:** FontAwesome 6, Google Fonts (*Plus Jakarta Sans* & *Space Grotesk*)
